## GitHub Copilot app (announced Microsoft Build, 2026-06-02)
- "the agent-native desktop experience built on GitHub". Technical preview for Copilot Pro, Pro+, Business, Enterprise; Copilot Max upgrade tier for higher volume.
- My Work view: sessions, issues, PRs, background automations.
- Each session in its own isolated git worktree; app manages worktrees.
- Canvases: "bidirectional work surfaces for humans and agents".
- Sandboxes: local restricted or cloud ephemeral Linux.
- Agent Merge: monitors CI, tracks required reviewers, fixes failing checks, waits for conditions before merging. "You decide what automation is enabled and what ships."
- Code review: new medium review tier on a higher-reasoning model; /security-review skill; /rubberduck (GA) "uses multiple model families to critique implementations". Copilot code review in Azure DevOps.

## Agent apps (changelog 2026-06-02)
- Partner agents installable from GitHub Marketplace: Amplitude, Bright Security, Endor Labs, LaunchDarkly, Miro, Sonar, PagerDuty, Packfiles, Octopus Deploy.
- Assigned via issue assignment, PR @mention, or Agents UI. Opening to all developers "over the coming months".

## Agent HQ (Universe, 2025-10-28; via search results)
- Mission Control: assign, steer and track agents across GitHub, Copilot CLI, VS Code; third-party agents (Anthropic, OpenAI, Google, Cognition, xAI) via paid Copilot subscription; branch controls, identity, one-click conflict resolution.
