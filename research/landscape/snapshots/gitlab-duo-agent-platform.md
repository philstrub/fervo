# GitLab Duo Agent Platform GA

- URL: https://about.gitlab.com/blog/gitlab-duo-agent-platform-is-generally-available/ ; press: https://about.gitlab.com/press/releases/2026-01-15-gitlab-announces-duo-agent-platform-general-availability/
- Fetched: 2026-10-21 (WebFetch; model-extracted summary)

- GA 2026-01-15 (GitLab 18.8) on GitLab.com, Self-Managed and Dedicated; Premium and Ultimate.
- Foundational agents (Planner, Security Analyst at GA); custom agents and flows via AI Catalog; external agents: Claude Code and Codex CLI "seamlessly integrated into GitLab".
- Flows: Developer (issue to MR), Convert to GitLab CI/CD, Fix CI/CD pipeline, Code Review, software development in IDE.
- MCP client with group-level controls and user approval; GitLab MCP server in beta.
- Model choice per top-level namespace (GPT-5 variants, Mistral, Llama, Claude); "supports self-hosted models for GitLab Self-Managed deployments".
- Pricing: GitLab Credits; $12 (Premium) / $24 (Ultimate) included per user per month (promotional); on-demand ~ $1/credit per earnings-call coverage.
- Governance: visibility of agent actions, namespace/group access controls, LDAP/SAML.
