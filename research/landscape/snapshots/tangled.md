# Tangled: federated git forge on AT Protocol

- URL: https://siliconangle.com/2026/03/02/tangled-announces-4-5m-round-build-github-alternative-built-blueskys-protocol/ ; docs https://docs.tangled.org/
- Fetched: 2026-10-21 (WebFetch; model-extracted summary)

- Tangled Labs Oy (Finland, founded 2025): "a next-generation federated social coding platform built atop the AT protocol".
- Repos, forks, stacked pull requests, CI, threaded issues; decentralized identity.
- Self-host repositories as "knots"; no central authority required.
- Agents as co-contributors: can create repos, submit PRs and review code via a full XRPC API.
- $4.5M seed led by byFounders; Bain Capital Crypto, Antler, Thomas Dohmke, Avery Pennarun and others.
- 7,000+ users, 5,000+ repos. 2026 plans: micro-VMs for builds, dashboard, GitHub migration tool, CLI. Pricing not stated (docs say hosting and CI free to use).
